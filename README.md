# \# 智能回复助手 (Smart Reply)

# 

# \[!\[License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

# \[!\[Version](https://img.shields.io/badge/version-1.1.0-blue)](https://github.com/yourusername/smart-reply)

# 

# 一款智能的消息回复生成工具，帮助你在不知道如何回复他人消息时，根据对话语境、双方关系和沟通场景，生成自然、真实、无AI味的高质量回复文字。

# 

# \## ✨ 核心特性

# 

# \### 🎯 精准理解语境

# \- 支持文字消息和聊天截图识别（微信/QQ/钉钉/飞书等）

# \- 自动分析多轮对话脉络、情绪倾向和潜在意图

# \- 识别对方消息中的套路/PUA/情感操控等风险模式

# 

# \### 🤝 场景化定制

# \- 适配多种关系类型：恋人/同事/领导/家人/客户等

# \- 支持不同回复目的：延续话题/化解尴尬/推进关系/委婉拒绝等

# \- 可自定义回复语气：幽默/真诚/专业/高冷/撒娇等

# 

# \### 💬 真人化回复

# \- 严格遵循去AI味规则，回复像真人聊天而非机器生成

# \- 适配不同场景的语言风格（口语化、网络用语、专业术语）

# \- 回复长短不一，情绪真实，符合真人聊天习惯

# 

# \### 🛡️ 智能风险提示

# \- 检测并提示潜在的沟通风险

# \- 提供反套路应对策略

# \- 保护用户沟通边界和情感安全

# 

# \## 🚀 适用场景

# 

# \### ✅ 适合使用的情况

# \- 不知道怎么回复对方消息，需要灵感

# \- 粘贴/截图聊天记录，需要生成合适回复

# \- 社交/职场/恋爱等场景的回复建议

# \- 需要多轮对话的回复策略

# \- 想识别对方消息中的潜台词或套路

# 

# \### ❌ 不适用的情况

# \- 单纯闲聊，无具体回复需求

# \- 需要语音回复或电话话术（仅支持文字）

# \- 要求自动发送消息（仅生成文字，不执行发送）

# \- 截图过于模糊或包含大量无关信息

# 

# \## 📋 使用流程

# 

# \### 1. 输入消息内容

# \- \*\*文字输入\*\*：直接粘贴对方的消息或多轮对话

# \- \*\*图片输入\*\*：上传聊天记录截图，自动识别内容

# 

# \### 2. 确认场景信息

# 工具会询问以下关键信息（按需提问，避免冗余）：

# \- 对方身份（关系类型）：恋人/同事/家人/客户等

# \- 回复目的：延续话题/化解尴尬/推进关系等

# \- 回复语气（可选）：幽默/真诚/专业等

# 

# \### 3. 生成回复选项

# 系统会生成3-5个不同风格的回复选项，每个选项包含：

# \- 风格标签和可直接复制的回复文字

# \- 适用场景和语气说明

# \- 风险提示（如检测到套路/操控）

# 

# \### 4. 优化调整

# 支持基于选择的选项进行微调：

# \- 调整语气（更温柔/更酷/更正式）

# \- 调整长度（更短/更长）

# \- 换角度表达

# \- 组合不同选项的特点

# 

# \## 🎭 关系适配特征

# 

# | 关系类型 | 语言特征 | 示例语气 |

# |----------|----------|----------|

# | 恋人/暧昧对象 | 亲密、撒娇、小作、甜 | "你才笨呢～"、"不想理你了（但还是在回）" |

# | 好朋友/闺蜜/兄弟 | 随意、互怼、吐槽、梗多 | "哈哈哈哈哈笑死"、"你认真的吗？" |

# | 同事/领导/老板 | 礼貌、简洁、不卑不亢 | "好的收到"、"我确认一下回复您" |

# | 家人/长辈 | 温和、耐心、恭敬 | "知道啦～"、"您放心，我会注意的" |

# | 客户/甲方 | 专业、积极、有分寸 | "感谢信任"、"这边尽快处理" |

# | 网友/陌生人 | 礼貌有距离、谨慎 | "哈哈是吗？"、"你也是哦" |

# | 前任 | 克制、大方、保持边界 | "嗯，挺好的"、"谢谢关心" |

# 

# \## 🚫 去AI味核心规则

# 

# \### 绝对禁止使用

# \- "我理解你的感受"、"作为一个..."等模板化表达

# \- 过于工整的排比句和作文式段落结构

# \- 过度使用"呢"、"呀"、"哦"等语气词

# \- 每条回复长度一致、句式雷同

# \- 书面语/新闻式表达、过度理性客观

# 

# \### 必须遵循

# \- 口语化表达，像微信聊天打字而非写作文

# \- 回复长短不一，允许不完整句子和跳跃逻辑

# \- 有真实情绪，允许小脾气、小撒娇

# \- 适当使用网络用语/俚语（根据场景）

# \- 适配时间场景（深夜更走心、工作时间更简洁）

# 

# \## 📸 截图处理能力

# 

# 上传聊天截图后，系统会自动：

# 1\. 识别聊天应用类型和对话双方

# 2\. 重建完整对话内容和时间线

# 3\. 推断双方关系和沟通氛围

# 4\. 向用户确认关键信息

# 5\. 处理特殊情况（群聊/多人/模糊截图等）

# 

# \## 💡 高级功能

# 

# \### 多轮对话分析

# 梳理对话脉络、情绪变化和关键转折点，基于整体语境生成回复。

# 

# \### 后续话题建议

# 在回复选项后提供1-2个可延续的话题方向，帮助持续沟通。

# 

# \### 反套路策略

# 检测到套路/操控时，提供：

# \- 套路类型分析

# \- 应对原则建议

# \- 安全回复选项

# 

# \### 语言自动适配

# \- 自动识别输入语言（中/英文）

# \- 回复语言与对方消息语言保持一致

# \- 支持中英混合场景的自然适配

# 

# \## 📝 示例

# 

# \### 示例1：暧昧对象回复

# \*\*对方消息\*\*："你今天怎么没找我？"

# \*\*场景\*\*：暧昧对象，想推进关系

# 

# ```

# \### 选项 1：\[小傲娇]

# > 我这不是在等你找我嘛

# 

# \*\*适用场景\*\*：对方语气带撒娇时，反客为主

# \*\*语气\*\*：俏皮、拉扯感

# 

# \### 选项 2：\[直球]

# > 找了啊 你没看到？

# 

# \*\*适用场景\*\*：想展示自己其实有关注对方

# \*\*语气\*\*：坦率、略带委屈

# 

# \### 选项 3：\[轻松化解]

# > 忙晕了都 你呢 今天干嘛了

# 

# \*\*适用场景\*\*：不想纠缠话题，自然转移

# \*\*语气\*\*：随意、自然

# 

# 💡 后续可以聊的方向：

# \- 分享今天做了什么（制造共同话题）

# \- 反问对方今天的状态

# ```

# 

# \### 示例2：检测到情感操控

# \*\*对方消息\*\*："你是不是不想理我了？我每次找你你都很敷衍"

# 

# ```

# 🛡️ 套路分析：

# 这句话可能是情感操控（guilt-tripping）的信号——通过让你产生内疚感来控制你的行为。

# 建议：不要急于道歉自证，先客观回应。

# 

# \### 选项 1：\[客观回应]

# > 哪有 我今天确实有点忙 不是针对你

# 

# \*\*适用场景\*\*：事实确实如此，平和解释

# \*\*语气\*\*：平静、不卑不亢

# 

# \### 选项 2：\[反问引导]

# > 怎么啦 是不是哪条消息让你觉得敷衍了？你跟我说说

# 

# \*\*适用场景\*\*：把模糊指责引导到具体事件

# \*\*语气\*\*：关心但不上套

# 

# ⚠️ 风险提示：不要回复"对不起是我不好"——这会强化对方的操控模式。

# ```
